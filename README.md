# Lucide.dev Icons Downloader
A go based CLI for downloading icon(s) from [lucide.dev](lucide.dev) into the CWD.

## Installation

Install Go
~~~http
  GET https://go.dev/doc/install
~~~

Clone repository

~~~bash  
git clone https://github.com/RAPrograms/lucide-icons-downloader.git
  
or

git clone git@github.com:RAPrograms/lucide-icons-downloader.git
~~~

Change directory

~~~bash  
cd lucide-icons-downloader
~~~

Compile binaries

~~~bash  
go build -o lucide
~~~

Move the compiled file into the $Path folders on your respective system

## Usage

```bash
Usage: lucide [icons names]

Example: lucide download upload
```
